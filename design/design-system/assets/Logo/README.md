# Logo
`setena-simbolo.svg`: símbolo de setena, cinco puntos `#5C48CB` (`palette-primary-40`) alrededor de dos círculos lima `#D4F06A` (`acento`) unidos. Es la geometría exacta con la que termina la animación de Inicio. Úsalo sobre fondo oscuro (`surface`).

El nombre «setena» no va en el archivo: se escribe como texto en Nunito Bold (estilos `logo-barra` y `logo-inicio`), siempre en minúsculas. Pendiente: la versión del nombre en trazos, para usos donde no se pueda cargar Nunito.
