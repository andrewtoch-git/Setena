# Mapa del wireframe

Qué componentes usa cada grupo de pantallas del lienzo «Wireframe App Music (FIDELIDAD MEDIA)», estado del 25/11. Los estados del sistema (cargando, errores, vacíos) se abren desde el lienzo en la prueba.

| Pantallas | Componentes |
|---|---|
| Inicio, Bienvenida | Animación de entrada «Encuentro» con el logotipo y el nombre «setena»; foto de fondo con degradado oscuro; titular «Conecta con músicos en tu misma frecuencia.» («Conecta» en peso 700 y `acento`); Botón (Regístrate gratis, Iniciar sesión, Empezar a explorar), Botón de icono («Cerrar y explorar sin cuenta») |
| Registro (+ campos obligatorios, correo ya registrado), Iniciar sesión (+ datos incorrectos), Recuperar contraseña | Barra superior (secundaria), Campo de texto, Selector de instrumento / géneros, Chip (Tipo de proyecto, Ubicación, Disponibilidad), Pestañas (Ubicación), Subida de vídeo, Casilla, Aviso, Botón |
| Explorar (con y sin registro, búsqueda por texto, filtros por instrumento, filtros aplicados, sin resultados, cargando, error de carga, sesión caducada) | Barra superior con logotipo, Barra de búsqueda, Chip, Tarjeta de músico (con foto y «Ver perfil» lima), aviso «Únete a la comunidad» (Regístrate con contorno), Etiqueta, Estado vacío, Indicador de carga, Barra de navegación, Ventana de registro, Ventana modal («Tu sesión ha caducado») |
| Filtros de búsqueda (con y sin registro) | Filtros de búsqueda, Chip, Botón |
| Perfil de músico (desde Explorar, Favoritos y chat; tarifas; compartir; más opciones; denunciar; bloquear; perfil mínimo; no disponible; sin registro) | Barra superior, Carrusel, Cabecera de perfil, Botón Favorito, Etiqueta, Pestañas, Sección de perfil, Fila de tarifa, Botón, Ventana de Compartir, Ventana modal, Casilla (opción única de denuncia), Aviso (bloqueo), Mensaje temporal, Estado vacío, Ventana de registro |
| Favoritos (+ vacío, sin registro) | Barra superior con logotipo, Elemento de lista (favorito), Botón de icono, Mensaje temporal con Deshacer, Estado vacío, Barra de navegación |
| Chats (+ vacío, sin registro, conversación nueva) | Barra superior con logotipo, Elemento de lista (chat), Insignia, Estado vacío, Barra de navegación |
| Chat (Jordi, Laia, Pau, Núria, Marc, Marta vacío y enviado, mensaje no enviado) | Barra superior (Chat), Burbuja de mensaje, Campo de envío, Ventana modal, Aviso (bloqueo), Barra de navegación |
| Mi perfil (+ tarifas, compartir, añadir foto o vídeo, error al subir, sin registro) | Barra superior con logotipo, Carrusel, Cabecera de perfil, Pestañas, Sección de perfil, Fila de tarifa, Ventana de Compartir, Subida de vídeo, Mensaje temporal, Barra de navegación |
| Editar perfil (+ falta el vídeo, instrumento o rol, géneros musicales, error al guardar) | Barra superior, Campo de texto, Selector de instrumento / géneros, Chip, Pestañas, Subida de vídeo, Aviso, Ventana modal (¿Salir sin guardar?, Cambios guardados), Botón |
| Ajustes (+ cambiar contraseña, contraseña incorrecta, cerrar sesión, eliminar cuenta) | Barra superior, Elemento de lista (ajustes), Interruptor, Campo de texto, Aviso, Ventana modal |
| Componentes, Guía visual | Fuente del inventario; la Guía visual se sustituye por los fundamentos de esta librería |
