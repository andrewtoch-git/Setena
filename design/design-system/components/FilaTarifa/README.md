# Fila de tarifa (pestaña Tarifas)
Precio orientativo por servicio, escrito por el propio músico.

**Pantallas:** Perfil de músico — pestaña Tarifas, Mi perfil — tarifas, Referencia — Perfil de músico completo.
**M3 Expressive:** List item de dos líneas con texto final. Estándar.

## Anatomía
1. Servicio `body-large`: «Bolo / Directo», «Grabación», «Composición», «Otros».
2. Descripción `body-medium` `on-surface-variant`: «Conciertos y eventos», «Instrumentos y voces», «Canciones y melodías», «Servicios adicionales».
3. Importe `title-medium-emphasized`: «120 €» (o «A convenir», o «—» si está vacío).
4. Unidad `body-small`: «por actuación», «por hora», «por proyecto» (solo si el importe empieza por un número).
5. «Otros»: texto libre en lugar de importe («Clases de guitarra: 20 € la hora»).
6. Nota final `body-small`: «Precios orientativos. El precio final se acuerda por chat.»

## Variantes
Con importe · «A convenir» · vacío («Aún no has añadido tarifas.» en Mi perfil).

Los importes son de ejemplo (decisión del equipo, 11/11).
