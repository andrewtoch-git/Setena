# Ventana de Compartir
Ventana flotante para compartir un perfil dentro o fuera de la app.

**Pantallas:** Perfil — compartir, Perfil — enviar a un chat, Perfil — perfil enviado; Mi perfil — compartir, enviar a un chat, perfil enviado.
**M3 Expressive:** Dialog (basic) con List. Estándar en su estructura; la fila de iconos de redes es PROPUESTA – pendiente de validar por el equipo.

## Anatomía
1. Título «Compartir perfil».
2. Texto: «¿Dónde quieres compartir el perfil de Marta Ruiz?» / «¿Dónde quieres compartir tu perfil?»
3. Encabezado «EN TUS CHATS» + fila «Enviar a un chat de la app» (`chevron_right`) → abre «Enviar a un chat» (casillas por chat + «Enviar» desactivado hasta elegir).
4. Encabezado «FUERA DE LA APP» + botones: WhatsApp (W), Instagram (I), Facebook (F), Más (•••). Logos oficiales pendientes.
5. «Cancelar».
6. Resultado: «¡Perfil enviado!» — «Has compartido el perfil de Marta Ruiz en {destino}.» — «Aceptar».
