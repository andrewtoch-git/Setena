# Sección de perfil (pestaña Info)
Bloques de información del perfil: Sobre mí, Disponibilidad y Redes sociales.

**Pantallas:** Perfil de músico (pestaña Info), Mi perfil (pestaña Info), Perfil mínimo.
**M3 Expressive:** texto + List (redes). Estándar.

## Anatomía
1. Título de sección `title-medium`: «Sobre mí», «Disponibilidad», «Redes sociales».
2. Contenido `body-medium`: texto libre; «El próximo fin de semana · Este mes» o «No indicada».
3. Redes: fila con marcador de marca (I, Y, S, T, SC), nombre de la red (`body-large`) e icono `open_in_new`.
4. Estados vacíos de Mi perfil: «Aún no has escrito nada sobre ti.», «Aún no has añadido redes sociales.»

## Pendiente
Iconos oficiales de Instagram, YouTube, Spotify, TikTok y SoundCloud: no se convierten en componente hasta tener el kit de marca de cada red.
