# Indicador de carga
Espera mientras se carga el catálogo.

**Pantallas:** Explorar — cargando («Cargando músicos…»).
**M3 Expressive:** Loading indicator (forma que cambia, 48 dp, `acento`). Estándar. La secuencia exacta de formas de M3 Expressive: a verificar (la vista previa la aproxima).

## Anatomía
Indicador 48 dp centrado + texto `body-medium` `on-surface-variant` «Cargando músicos…». `role="status"`.

## Uso
Esperas indeterminadas de pantalla completa. Para subidas de archivos, usar el mensaje temporal con progreso.
