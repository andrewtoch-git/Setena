# Subida de vídeo y foto
Añadir, titular, marcar como principal y quitar vídeos; el vídeo es obligatorio (decisión del equipo, 10/11).

**Pantallas:** Registro, Editar perfil, Mi perfil — editar, falta el vídeo, Mi perfil — añadir foto o vídeo, Mi perfil — error al subir un vídeo.
**M3 Expressive:** composición (List item + Outlined text field + Button + Dialog + Snackbar). PROPUESTA – pendiente de validar por el equipo.

## Anatomía (formulario)
1. Título «Vídeo» + «(obligatorio)».
2. Fila de vídeo: miniatura 16:9, nombre de archivo («directo_trio_jazz.mp4»), campo «Título del vídeo», etiqueta «Principal» o botón de texto «Hacer principal», botón de texto «Quitar».
3. Botón con contorno «Añadir vídeo» (`add`).
4. Ayuda: «El vídeo marcado como «Principal» es el que se ve arriba en tu perfil.» / «¡Elige ese vídeo que te encanta y comparte tu talento con la comunidad!»
5. Error: «Este campo es obligatorio».

## Anatomía (Mi perfil → «Añadir»)
Ventana «Añadir a tu perfil»: «Subir vídeo — MP4 o MOV, hasta 100 MB», «Subir foto — JPG o PNG, hasta 10 MB», «Cancelar». Progreso y resultado con mensaje temporal («Subiendo vídeo…», «Vídeo subido. Puedes marcarlo como principal.», error con «Reintentar»).
